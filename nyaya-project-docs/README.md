# Nyaya project docs

These six documents are the planning/implementation contract for the Nyaya MVP.

Recommended reading order:
1. `PRD.md` — what to build and acceptance criteria
2. `Rules.md` — safety and non-negotiable invariants
3. `Architecture.md` — system boundaries and API outline
4. `Design.md` — screens, interaction, accessibility, copy
5. `Phases.md` — implementation sequence and exit criteria
6. `Memory.md` — working context for Claude Code

`Memory.md` is the only document intended to be updated by Claude Code during implementation. Treat the other five as read-only unless the user explicitly authorizes a change.

Important: this is a specification pack, not a claim that application code or external integrations already exist. The worker host, exact scoring rubric, official service routes, and provider capabilities still require verification before they are treated as settled.
